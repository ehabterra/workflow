About Metadata

  • Metadata can be defined at workflow, place, and transition levels
  • Metadata is stored in the workflow definition and accessible via the API
  • Use metadata to store UI hints, icons, descriptions, and other application-specific data
  • Metadata does not affect workflow logic but can be used by your application
